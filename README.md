# Smart Expense Tracker with AI Insights

## Overview
Smart Expense Tracker with AI Insights is a web-based application developed to help users manage their daily financial activities in a simple and organized way. The project allows users to record income and expenses, track spending habits, and view financial reports through an interactive dashboard.

The main purpose of this project is to make expense management easier for students, employees, and regular users who want to monitor their financial activities and improve their budgeting habits.

---

## Problem Statement
Many people find it difficult to track where their money is being spent. Traditional methods like writing expenses in notebooks are time-consuming and difficult to maintain. This project provides a digital solution where users can store and analyze their financial records efficiently.

---

## Objectives
- To develop a simple expense management system
- To help users maintain daily financial records
- To provide graphical analysis of expenses
- To generate AI-based spending insights
- To improve budgeting and financial awareness

---

## Features

## Working of the Project
The user first creates an account and logs into the system. After login, the user can add income and expense records by selecting categories and entering transaction details. The application stores the data securely in the database and displays summaries using charts and reports.

The AI Insights module analyzes the spending patterns and provides useful suggestions such as identifying high-expense categories and helping users control unnecessary spending.
